# 离线画质与流畅度图案

在被控机用浏览器打开同目录的 `quality-scene.html`；不需要服务器、安装依赖、联网或授予权限。电脑可按 F11 进入浏览器全屏，再点击“只展示图案”腾出控制栏空间；右上角保留缩放提示与“返回设置”。它是人工观察素材，不接入生产客户端，也不自动测量远程画质或延迟。

1. 先保持静止，选择 720p 或 1080p 图案。记录被控机屏幕分辨率、系统缩放、浏览器缩放、设备型号、远程客户端缩放与连接模式。
2. 检查页面提示。只有源端未经缩放的 1:1 像素映射，并且远端同样 1:1 显示，才适合判断单像素细线和小字清晰度。自动适配会缩小图案；高 DPI、浏览器缩放及手机手势缩放也会影响结果。原始 CSS 尺寸模式可滚动查看完整图案。
3. 观察 9/12/14 px 中英文文字、代码、表格与红蓝单像素边缘；分别记录能否辨认、模糊、色边混合与块状失真。不同机器的本地字体可能不同，同一轮对比应使用同一被控机与浏览器。
4. 选择 30 或 60 帧/秒，点击“启动动画”。观察移动块是否连贯、滚动文字是否拖影，以及暂停后画质恢复情况。点击“重置至第 0 帧”可重复相同的动画时间线。页面转入后台会自动暂停；恢复前台后手动继续。

页面显示源图案像素、实际 CSS 渲染尺寸、图案缩放、`devicePixelRatio` 与手势缩放。1:1 状态按未经缩放的源像素判断，不能验证远程客户端、操作系统截图或显示器是否另有缩放。窗口较小或缩放条件不满足时，清晰度测量无效，仍可粗略观察流畅度。

“本机 rAF”是一秒窗口内 `requestAnimationFrame` 的回调频率；60 Hz 浏览器运行 30 帧/秒图案时，rAF 仍可能约为 60。实际绘制次数是此页面动画循环提交 Canvas 绘制的次数，图案帧号是目标时间线上所在的帧：浏览器繁忙时可跳号。两者均不是远程收到、解码或呈现的帧数，不能当作网络/操作延迟或帧丢失率。动画时间也不是两台设备间同步的时钟。

每次 A/B 对比应固定图案尺寸、缩放、目标帧率、浏览器、设备、电源及网络条件。此图案有助于发现问题；最终判断还需远程客户端统计、真机操作和对应的视频链路测量。
