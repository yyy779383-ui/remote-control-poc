# 设备与网络测试矩阵

## 最小实验室

| 编号 | 设备 | 覆盖风险 |
|---|---|---|
| W1 | Windows 10、Intel 8 代/UHD 620 级、8GB、1080p60 | 老旧个人和 IT 设备下限 |
| W2 | 当前 Windows 11、16GB、核显+独显、双屏 | 硬编、多屏、DPI、4K 和现代驱动 |
| A1 | Android 10/11 中低端大陆 ROM | 性能下限、后台限制 |
| A2 | Android 14/15 OPPO、vivo 或 Honor 中端机 | 大陆主流 ROM |
| A3 | Android 15/16 Samsung | 美国、欧洲常见设备和 SoC |
| A4 | Android 16 Pixel 6 或以上 | AOSP 与最新系统基线 |
| N1 | OpenWrt 路由器或双网卡 Linux 小主机 | 双向限速、延迟、抖动、丢包和断网 |

首发 Android 最低版本暂定 Android 10。HarmonyOS NEXT 不属于 Android APK 首发范围。真机可以使用现有或借用设备；模拟器和云手机不能代替硬编、发热、厂商后台限制和触控手感测试。

## 设备配对

- W1 ↔ W2，双方轮流担任主控和被控。
- W1/W2 分别控制 A1–A4，每台 Android 都必须担任被控端。
- A1–A4 分别控制 W1/W2，每台 Android 都必须担任主控端。
- A1 ↔ A4、A2 ↔ A3，双向验证 Android 到 Android。

## 网络档位

| 编号 | RTT / 抖动 / 丢包 | 被控端上行 | 验证目标 |
|---|---|---:|---|
| N0 局域网 | ≤5 ms / ≤1 ms / 0 | ≥100 Mbps | 硬件和本地管线上限 |
| N1 同城宽带 | 20 ms / 3 ms / 0.1% | 20 Mbps | 日常固定网络 |
| N2 普通移动网 | 60 ms / 15 ms / 1% | 5 Mbps | 4G/5G 和一般 Wi-Fi |
| N3 弱网 | 120 ms / 30 ms / 3% | 1.5 Mbps | 自动降清晰度但保持可操作 |
| N4 跨洲 | 220 ms / 40 ms / 1% | 5 Mbps | 中美、中欧路径 |
| N5 极差/回退 | 300 ms / 60 ms / 5%，禁用 UDP | 0.8 Mbps | TCP/TLS 443 回退且不累积时延 |
| N6 切网 | 断网 5 秒并更换 IP | 动态 | Wi-Fi/5G 切换和会话恢复 |

每个核心档位都分别测试 P2P UDP、强制中继和 UDP 被封后的 TCP/TLS 443 回退。

## 必测用例

1. IDE、终端、Excel、8–14 px 中英文字体和细线。
2. 网页滚动、拖动窗口、60FPS 运动图和全屏视频。
3. 点击、双击、拖拽、滚轮、长按、中英文输入法和 Android 系统导航。
4. Windows 多屏、DPI、UAC、锁屏、服务重启和显卡驱动异常。
5. Android 授权同意/拒绝、横竖屏、熄屏、来电、低电量和后台清理。
6. 直连失败转中继、CGNAT、IPv4/IPv6、UDP 封锁、切网和短时断网。
7. 四个方向各连续 2 小时，Windows → Windows 和 Android → Android 各进行一次 8 小时测试。

## 人工操作边界

Codex 可自动化构建、安装、连接循环、网络档位、指标采集、SSIM/OCR 和报告。以下事项需要现场人工完成：

- Android 录屏、无障碍授权和厂商后台保活。
- UAC、安全桌面、锁屏、插拔显示器和设备重启。
- 使用 240FPS 摄影的手机拍摄真实“输入到画面”延迟。
- 字体清晰度、触摸手感和主观流畅度盲测。
