## 测试边界

- Windows 包检查只执行 `--version`，不打开远控窗口、不启动常驻服务、不自动提权。
- 本机 benchmark 只测采集、转换、编码、解码，不测网络、远端显示或输入响应。结果只保存在本机；工具不上传画面。
- 首次硬件编码探测和正常编解码都由外部进程超时约束，避免驱动无响应时无限等待。
- Android 使用独立包名和固定测试签名；还需要真机上的录屏授权、无障碍授权、撤销授权与断连测试。
- Windows 仍使用上游 RustDesk 应用身份。正常打开 GUI 可能使用已有 RustDesk 配置；完成隔离策略前，不把当前包当作可与官方客户端完全独立共存的正式产品。
