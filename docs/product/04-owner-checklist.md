# 产品所有者准备清单

Codex 可以负责代码、构建脚本、测试工具、服务端配置、文档和发布流程。物理设备上的授权、体感评价、商店/云厂商身份和最终商业责任需由产品所有者提供。

## 现在需要

- 一台可用于编译和调试的 Windows 10/11 x64 电脑。
- 至少一台 Android 11 或以上真机和可用 USB 数据线。
- 允许在测试机上开启开发者选项、USB 调试、录屏和无障碍服务。
- 家庭宽带和一个可用的手机热点，用于两种独立网络测试。

## 进入第 4 周前需要

- 第二台 Windows 电脑，最好与第一台使用不同 GPU 厂商。
- 理想情况下准备四个 Android 品牌的真机；最低可先用三台启动，但必须包含一台中低端大陆机、一台近两年的中高端机和一台 Samsung/Pixel 海外基线机。
- 可从中国大陆访问的临时测试节点；跨境测试时再开通新加坡、美国西部和法兰克福节点。

## Beta 前才需要

- 产品中英文名称、域名和 Logo。
- 组织名义的 Google Play 开发者账号。
- Windows 代码签名或 Microsoft Store 发布路线。
- 中国大陆网站/服务器所需的主体、备案和隐私文件。
- 安全审计和开源许可证复核预算。

## 暂时不需要决定

- 最终套餐价格。
- 正式节点数量和长期带宽合同。
- 企业私有化版功能。
- 4K、HDR、高帧率游戏和专业设计功能。
